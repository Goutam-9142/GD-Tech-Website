Top Advanced Java Interview Questions & Answers

📖 Chapter 1 : JDBC

Q1. What is Advanced Java?

Advanced Java is used to develop web-based, database-driven, and enterprise applications using technologies such as JDBC, Servlets, JSP, and APIs.

Q2. What is JDBC?

JDBC (Java Database Connectivity) is a Java API used to connect Java applications with databases.

Q3. What are the main steps in JDBC?

The main steps are loading the driver, creating a connection, creating a statement, executing SQL, processing the result, and closing the connection.

Q4. What is JDBC Driver?

A JDBC Driver is software that allows a Java application to communicate with a specific database.

Q5. What is Connection in JDBC?

Connection represents a connection between a Java application and a database.

Q6. What is Statement?

Statement is used to execute SQL queries against a database.

Q7. What is PreparedStatement?

PreparedStatement is used to execute parameterized SQL queries. It improves performance and helps prevent SQL injection.

Q8. What is ResultSet?

ResultSet stores the data returned by a database query, usually a SELECT query.

Q9. What is CRUD?

CRUD stands for Create, Read, Update, and Delete. These are the basic operations performed on database data.

Q10. What is the difference between Statement and PreparedStatement?

Statement executes normal SQL queries, while PreparedStatement supports parameterized queries and is generally safer and more efficient.

📖 Chapter 2 : Servlets & JSP

Q11. What is a Servlet?

A Servlet is a Java program that runs on a web server and is used to handle client requests and generate responses.

Q12. What is the Servlet Life Cycle?

The main stages are loading, initialization using init(), request processing using service(), and destruction using destroy().

Q13. What is doGet()?

doGet() is used to handle HTTP GET requests, commonly for retrieving data from the server.

Q14. What is doPost()?

doPost() is used to handle HTTP POST requests, commonly for sending form data to the server.

Q15. What is HttpServletRequest?

HttpServletRequest is used by a Servlet to access information sent by the client, such as form parameters and request details.

Q16. What is HttpServletResponse?

HttpServletResponse is used by a Servlet to send a response back to the client.

Q17. What is JSP?

JSP (JavaServer Pages) is a technology used to create dynamic web pages using HTML and Java-based server-side features.

Q18. What is the JSP Life Cycle?

The JSP is translated into a Servlet, compiled, initialized, executed for requests, and finally destroyed.

Q19. What are JSP Directives?

JSP directives provide instructions to the JSP container. Common directives are page, include, and taglib.

Q20. What is the difference between Servlet and JSP?

Servlets are mainly used for request processing and control logic, while JSP is mainly used for creating the presentation or web-page layer.

📖 Chapter 3 : Sessions, MVC & Web Technologies

Q21. What is Session Management?

Session Management is used to maintain information about a user across multiple requests.

Q22. What is a Cookie?

A Cookie is a small piece of data stored by the browser and sent with requests to the server.

Q23. What is HttpSession?

HttpSession is used to store user-specific information on the server across multiple requests.

Q24. What is MVC?

MVC stands for Model, View, and Controller. It separates application data, user interface, and control logic.

Q25. What is a Filter?

A Filter is used to process requests and responses before or after they reach a Servlet. It can be used for logging, authentication, and validation.

Q26. What is a Listener?

A Listener monitors events occurring in a web application, such as session creation or application startup.

Q27. What is REST API?

A REST API is an interface that allows applications to communicate over HTTP using methods such as GET, POST, PUT, and DELETE.

Q28. What is JSON?

JSON (JavaScript Object Notation) is a lightweight data format commonly used to exchange data between a client and a server.

Q29. What is Authentication?

Authentication is the process of verifying the identity of a user, such as checking a username and password.

Q30. What is Authorization?

Authorization determines what an authenticated user is allowed to access or perform in an application.
