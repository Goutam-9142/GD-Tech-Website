📖 Chapter 1 : Node.js Basics

Q1. What is Node.js?

Node.js is an open-source JavaScript runtime environment used to build fast and scalable server-side applications.

Q2. Why is Node.js used?

Node.js is used for backend development, REST APIs, real-time applications, file handling, and scalable web applications.

Q3. What is the V8 Engine?

V8 is Google's JavaScript engine that executes JavaScript code quickly. It is used by Node.js.

Q4. What are the features of Node.js?

Node.js is fast, asynchronous, event-driven, non-blocking, lightweight, scalable, and cross-platform.

Q5. What is NPM?

NPM (Node Package Manager) is used to install, update, and manage Node.js packages and libraries.

Q6. What is package.json?

package.json is a configuration file that stores project information, dependencies, scripts, and metadata.

Q7. What is REPL in Node.js?

REPL stands for Read, Evaluate, Print, and Loop. It is an interactive environment used to execute JavaScript code.

Q8. What are Modules in Node.js?

Modules are reusable pieces of code that help organize applications into smaller files.

Q9. What is the difference between CommonJS and ES Modules?

CommonJS uses require() and module.exports, while ES Modules use import and export.

Q10. What is module.exports?

module.exports is used to export functions, objects, or variables from one module so they can be used in another module.

📖 Chapter 2 : Node.js Core Modules

Q11. What are Built-in Modules in Node.js?

Built-in modules are pre-installed modules provided by Node.js, such as fs, http, path, os, and events.

Q12. What is the HTTP Module?

The HTTP module is used to create web servers and handle HTTP requests and responses.

Q13. What is the File System (fs) Module?

The fs module is used to create, read, update, rename, and delete files.

Q14. What is the Path Module?

The path module provides utilities for working with file and directory paths.

Q15. What is the OS Module?

The os module provides information about the operating system, such as CPU, memory, platform, and hostname.

Q16. What is EventEmitter?

EventEmitter is a class from the events module that allows you to create and handle custom events.

Q17. What is a Stream in Node.js?

Streams are used to read or write data continuously without loading the entire file into memory.

Q18. What is a Buffer?

A Buffer is a temporary memory area used to store binary data while reading or writing files and network data.

Q19. What is the difference between Synchronous and Asynchronous methods?

Synchronous methods execute one task at a time and wait for completion, while Asynchronous methods execute tasks without blocking other operations.

Q20. Why is Node.js called Non-Blocking?

Node.js uses a non-blocking, asynchronous I/O model, allowing multiple operations to run efficiently without waiting for previous tasks to finish.

📖 Chapter 3 : Advanced Node.js Interview Questions

Q21. What is a Callback Function?

A callback is a function passed as an argument to another function and is executed after the completion of a task.

Q22. What is a Promise?

A Promise is an object that represents the eventual completion or failure of an asynchronous operation.

Q23. What is Async/Await?

Async/Await is a modern way to handle asynchronous code, making it easier to read and write than callbacks or promise chains.

Q24. What is Express.js?

Express.js is a fast and lightweight web framework for Node.js used to build web applications and REST APIs.

Q25. What is Middleware in Express.js?

Middleware is a function that executes between the request and the response. It can modify requests, responses, or pass control to the next middleware.

Q26. What is REST API?

REST API is an architectural style that allows communication between client and server using HTTP methods such as GET, POST, PUT, and DELETE.

Q27. What is MongoDB?

MongoDB is a NoSQL database that stores data in JSON-like documents instead of tables.

Q28. What is Mongoose?

Mongoose is an Object Data Modeling (ODM) library that helps connect Node.js applications with MongoDB.

Q29. What is JWT?

JWT (JSON Web Token) is a secure token used for user authentication and authorization in web applications.

Q30. Why should we learn Node.js?

Node.js is fast, scalable, and widely used for backend development, REST APIs, real-time applications, and full-stack JavaScript development.
