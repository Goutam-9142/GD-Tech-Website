Top CSS Interview Questions & Answers

📖 Chapter 1 : CSS Basics

Q1. What is CSS?

CSS (Cascading Style Sheets) is used to style and design HTML web pages.

Q2. What are the types of CSS?

There are three types of CSS: Inline CSS, Internal CSS, and External CSS.

Q3. What is the difference between Inline, Internal and External CSS?

Inline CSS is written inside an HTML tag, Internal CSS is written inside the <style> tag, and External CSS is written in a separate .css file.

Q4. What are CSS Selectors?

Selectors are used to target HTML elements for styling, such as element, class, id, and universal selectors.

Q5. What is the difference between ID and Class?

An ID is unique for one element, while a class can be used for multiple elements.

Q6. What is the CSS Box Model?

The Box Model consists of Content, Padding, Border, and Margin.

Q7. What is Margin?

Margin creates space outside the border of an element.

Q8. What is Padding?

Padding creates space between the content and the border of an element.

Q9. What is Border?

Border is the outline that surrounds an element's padding and content.

Q10. What is the difference between Margin and Padding?

Margin creates space outside the element, while Padding creates space inside the element.

📖 Chapter 2 : CSS Layout & Styling

Q11. What is the Display Property?

The display property defines how an HTML element is displayed, such as block, inline, inline-block, flex, and grid.

Q12. What is the difference between Block and Inline Elements?

Block elements take the full width available, while inline elements only take the width of their content.

Q13. What is Position in CSS?

The position property controls the placement of elements. Common values are static, relative, absolute, fixed, and sticky.

Q14. What is the difference between Relative and Absolute Position?

Relative positions an element from its normal position, while Absolute positions an element relative to its nearest positioned ancestor.

Q15. What is Flexbox?

Flexbox is a one-dimensional layout system used to align and distribute space between items efficiently.

Q16. What is CSS Grid?

CSS Grid is a two-dimensional layout system used to create complex row and column layouts.

Q17. What is the difference between Flexbox and Grid?

Flexbox is mainly for one-dimensional layouts, while Grid is designed for two-dimensional layouts with rows and columns.

Q18. What is the z-index Property?

The z-index property controls the stacking order of overlapping elements.

Q19. What is Overflow in CSS?

The overflow property controls what happens when content is larger than its container. Values include visible, hidden, scroll, and auto.

Q20. What is the Difference between Visibility and Display?

display:none removes the element from the page layout, while visibility:hidden hides the element but keeps its space reserved.

📖 Chapter 3 : Advanced CSS Interview Questions

Q21. What are Media Queries?

Media Queries are used to create responsive websites by applying different CSS styles for different screen sizes.

Q22. What is Responsive Web Design?

Responsive Web Design (RWD) ensures that a website looks good and works properly on mobiles, tablets, and desktops.

Q23. What is the Transition Property?

The transition property creates smooth animations when CSS property values change.

Q24. What is Transform in CSS?

The transform property is used to rotate, scale, move, or skew an element.

Q25. What is Animation in CSS?

CSS Animation allows elements to change styles over time using the @keyframes rule.

Q26. What are Pseudo Classes?

Pseudo classes define a special state of an element, such as :hover, :focus, :active, and :visited.

Q27. What are Pseudo Elements?

Pseudo elements style specific parts of an element, such as ::before, ::after, ::first-letter, and ::first-line.

Q28. What is CSS Specificity?

Specificity is the rule that decides which CSS style will be applied when multiple selectors target the same element.

Q29. What are CSS Variables?

CSS Variables are custom properties declared using --variable-name and accessed with the var() function.

Q30. Why should we learn CSS?

CSS is essential for creating attractive, responsive, and modern websites. It controls layout, colors, fonts, spacing, animations, and overall user experience.
