Top HTML Interview Questions & Answers

📖 Chapter 1 : HTML Basics

Q1. What is HTML?

HTML (HyperText Markup Language) is the standard markup language used to create the structure of web pages.

Q2. What is HTML5?

HTML5 is the latest version of HTML that supports semantic tags, multimedia, canvas, SVG, local storage, and modern web features.

Q3. What are HTML Tags?

HTML tags are predefined keywords enclosed in angle brackets that define the structure and content of a webpage.

Q4. What is an HTML Element?

An HTML element consists of a start tag, content, and an end tag.

Q5. What are HTML Attributes?

Attributes provide additional information about HTML elements, such as id, class, href, src, and alt.

Q6. What is the purpose of <!DOCTYPE html>?

The <!DOCTYPE html> declaration tells the browser that the document is written in HTML5.

Q7. What are Semantic Tags?

Semantic tags clearly describe the meaning of the content, such as <header>, <nav>, <main>, <section>, <article>, and <footer>.

Q8. What is the difference between Block and Inline Elements?

Block elements take the full available width, while inline elements only take the space required by their content.

Q9. What is the difference between ID and Class?

An id is unique and should be used for only one element, whereas a class can be used for multiple elements.

Q10. What is the purpose of the <head> tag?

The <head> tag contains metadata such as the page title, meta tags, CSS links, JavaScript files, and favicon.

📖 Chapter 2 : HTML Forms & Media

Q11. What is the difference between <div> and <span>?

The <div> tag is a block-level element, while the <span> tag is an inline element.

Q12. What is the purpose of the <head> tag?

The <head> tag contains metadata such as the page title, CSS links, icons, and scripts.

Q13. What is the purpose of the <meta> tag?

The <meta> tag provides information about the webpage like character encoding, viewport, author, and description.

Q14. What is the difference between <ol> and <ul>?

<ol> creates an ordered (numbered) list, while <ul> creates an unordered (bulleted) list.

Q15. What is the purpose of the <a> tag?

The <a> (anchor) tag is used to create hyperlinks between web pages or resources.

Q16. What is the purpose of the <img> tag?

The <img> tag is used to display images on a webpage using the src attribute.

Q17. What is the purpose of the alt attribute?

The alt attribute provides alternative text if an image cannot be displayed and also improves accessibility.

Q18. What are HTML Forms?

HTML forms are used to collect user input using elements like input, textarea, select, button, and form.

Q19. What are the common input types in HTML?

Common input types include text, password, email, number, date, radio, checkbox, file, submit, and reset.

Q20. What is the purpose of the <label> tag?

The <label> tag is used to provide a text label for form controls, improving usability and accessibility.

📖 Chapter 3 : HTML5 Advanced Interview Questions

Q21. What is the purpose of the <table> tag?

The <table> tag is used to display data in rows and columns using table, tr, th, and td elements.

Q22. What is the difference between <th> and <td>?

<th> defines a table header (bold and centered by default), while <td> defines a table data cell.

Q23. What is the purpose of the <iframe> tag?

The <iframe> tag is used to embed another webpage or external content inside the current webpage.

Q24. What are HTML5 Semantic Elements?

Semantic elements include <header>, <nav>, <main>, <section>, <article>, <aside>, and <footer>.

Q25. What is the purpose of the <audio> tag?

The <audio> tag is used to play audio files directly in the browser without external plugins.

Q26. What is the purpose of the <video> tag?

The <video> tag is used to embed and play video files in HTML5.

Q27. What is the Canvas element?

The <canvas> element is used to draw graphics, animations, charts, and games using JavaScript.

Q28. What is SVG in HTML?

SVG (Scalable Vector Graphics) is used to create high-quality vector graphics that can be scaled without losing quality.

Q29. What is the difference between Local Storage and Session Storage?

Local Storage stores data permanently until it is removed, while Session Storage stores data only until the browser tab is closed.

Q30. Why should we learn HTML?

HTML is the foundation of web development. It is used to create the structure of websites and works together with CSS and JavaScript to build modern web applications.
