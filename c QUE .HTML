Top C Language Interview Questions & Answers

📖 Chapter 1 : C Basics

Q1. What is C?

C is a general-purpose programming language used to develop system software, applications, operating systems, and embedded programs.

Q2. Who developed C language?

C language was developed by Dennis Ritchie at Bell Labs in the early 1970s.

Q3. What are the features of C?

C is simple, fast, portable, structured, and supports pointers, functions, arrays, and memory management.

Q4. What is a variable?

A variable is a named memory location used to store a value that can change during program execution.

Q5. What are data types in C?

Data types define the type of data a variable can store. Examples are int, float, char, and double.

Q6. What is a constant?

A constant is a value that does not change during program execution.

Q7. What is a keyword?

A keyword is a reserved word in C that has a special meaning, such as int, if, else, return, and while.

Q8. What is a compiler?

A compiler converts C source code into machine code that the computer can execute.

Q9. What is the use of printf()?

The printf() function is used to display output on the screen.

Q10. What is the use of scanf()?

The scanf() function is used to take input from the user.

📖 Chapter 2 : Operators, Conditions & Loops

Q11. What are operators in C?

Operators are symbols used to perform operations on values. Examples include +, -, *, /, %, ==, &&, and ||.

Q12. What is the difference between = and ==?

= is the assignment operator, while == is the comparison operator used to check whether two values are equal.

Q13. What is an if statement?

The if statement is used to execute a block of code when a condition is true.

Q14. What is a switch statement?

The switch statement is used to select one block of code from multiple choices.

Q15. What is a loop?

A loop is used to execute a block of code repeatedly until a particular condition is satisfied.

Q16. What are the types of loops in C?

The three main loops are for loop, while loop, and do-while loop.

Q17. What is the difference between while and do-while?

while checks the condition before execution, whereas do-while executes the code at least once before checking the condition.

Q18. What is break?

The break statement is used to immediately exit from a loop or switch statement.

Q19. What is continue?

The continue statement skips the current iteration and moves to the next iteration of the loop.

Q20. What is a function?

A function is a block of code designed to perform a specific task. It helps make programs reusable and organized.

📖 Chapter 3 : Arrays, Pointers & Memory

Q21. What is an array?

An array is a collection of elements of the same data type stored in continuous memory locations.

Q22. What is a string in C?

A string is a sequence of characters terminated by a null character \0.

Q23. What is a pointer?

A pointer is a variable that stores the memory address of another variable.

Q24. What is the use of & operator?

The & operator is called the address-of operator. It is used to get the memory address of a variable.

Q25. What is the use of * operator with pointers?

The * operator is used to access the value stored at the memory address held by a pointer.

Q26. What is a structure?

A structure is a user-defined data type that can store different types of data under one name.

Q27. What is dynamic memory allocation?

Dynamic memory allocation means allocating memory during program execution using functions such as malloc(), calloc(), realloc(), and free().

Q28. What is the difference between malloc() and calloc()?

malloc() allocates a block of memory without initializing it, while calloc() allocates memory and initializes it to zero.

Q29. What is recursion?

Recursion is a process in which a function calls itself to solve a problem.

Q30. What is the difference between C and C++?

C is mainly a procedural programming language, while C++ supports both procedural programming and object-oriented programming.
